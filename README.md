# 異変探しゲーム

## 概要

長期インターンシップにおいて制作した個人開発の異変探しゲームです。

プレイヤーは日常風景に紛れ込んだ異変を探しながらゲームを進めます。また、恋愛シミュレーションゲームのような会話パートを導入し、ストーリーを楽しみながら遊べる構成にしました。

## 開発環境

* Unity 6000.2.7f2
* C#
* Visual Studio
* Photoshop

## 開発期間

約2か月

## 担当領域

* 企画立案
* 仕様書作成
* プログラミング
* UI制作
* レベルデザイン

## 実装機能

* 異変探しシステム
* 異変のランダム出現機能
* 難易度選択機能
* 会話イベント機能
* UI画面遷移

## 工夫した点

### 異変の重複防止

単純なランダム処理では同じ異変が繰り返し表示されるため、出現済みの異変を管理する仕組みを実装しました。

これにより、同一プレイ内で異変が重複せず、毎回異なる体験を提供できるようにしました。

### レベルデザイン

異変が簡単すぎても難しすぎても面白さが損なわれるため、「気づけそうで気づけない違和感」を意識して配置を調整しました。

テストプレイを繰り返し行いながら難易度を調整し、幅広いプレイヤーが楽しめるゲームを目指しました。

## 学んだこと

本作品の開発を通じて、機能を実装するだけでなく、プレイヤー体験を考えながら設計・改善を行う重要性を学びました。

また、企画から実装までを一人で担当したことで、開発工程全体を見渡しながら制作を進める経験を得ることができました。
